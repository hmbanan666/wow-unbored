# 0035. Personal-only tooltip Advice

Status: accepted (amended by [0048](0048-account-holdings-in-tooltips.md))

The tooltip shows a Wisp line only with a personal signal: Alt routing, an item needed for the current Plan, new for the Account's collection, a quest-starting item this character has not done, or Personal advice (D75). Generic lines and the bundled Advice table are removed; no line is the default, and the setting "Wisp lines in tooltips" turns them off. This amends [0019](0019-tooltip-advice.md).
