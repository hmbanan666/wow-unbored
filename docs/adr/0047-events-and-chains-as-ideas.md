# 0047. Events and quest chains as ideas

Status: accepted

Calendar events (with Timewalking) and unfinished quest chains become ideas built from the player's own data, by the addon live and by the Server from the `calendar` and `questLines` Sections, shown only while they still give this player something (D126-D138). The choice Bubble shows up to 4 ideas, then [Surprise me] [More ideas]; the Server sends up to 10 per Character, and a picked Chain starts a local Quick plan with no reload (D139-D141). This amends [0040](0040-suggestions-from-data.md).
