# 0021. Account personalization and Alt routing

Status: accepted

Personalization is per Account: the Server links every character's profile, Requests and history to its Account and MCP reads can take the whole Account. The addon keeps an account-wide registry of Alts (professions, skills, level, class, realm, refreshed at each login) so Advice can route an item to an Alt with no Server: warband bank for warbound items, mail otherwise, never for soulbound items (D40-D43).
