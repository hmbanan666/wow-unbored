# 0072. Paths

Status: accepted

A **Path** is a curated set of goals for one piece of content ("Midnight: Basic"). It has a tier (Basic, Deeper, Complete; a deeper tier lists the previous one as prerequisite) and optional **Topics** (mounts, achievements, PvP) that group its goals. Each **Path goal** is one Plan outcome kind (rep, renown, level, achievement, currency, mount, pet, toy, item) or `quest` / `questLine`, referencing ids verified in the Game DB, with an optional required flag (required goals define completion). Paths are versioned data in `packages/contracts/paths/`, drafted with sources, checked in CI against the Game DB, and loaded by the Server; players do not author them. Progress is computed by the Server per Character from the Game data snapshot (account-wide goals from Account Sections), as done of total required goals. A Character has at most one active Path, set from the website or an in-game Idea; Ideas offer "Continue your Path" and Plans for it take their outcome from the next unfinished goals. Reaching all required goals records a **Path completion** in Player history (once per Character and Path version), like a Win.
