# 0019. Tooltip Advice

Status: accepted

Every bag and bank item tooltip gets one teal "Wisp: <action>" line (two with a quest pin): an action, not an explanation, from the first matching rule. Three sources, none needing a reload: local rules on live APIs, a bundled Advice table, and Personal advice written by the Companion; v1 never says delete and never vendor for epic or BoE items, shows AH prices only through Auctionator or TSM, and logs unmatched item ids to the profile (D31-D36).
