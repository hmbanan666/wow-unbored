# 0098. Deterministic profession skill Plans

Status: accepted (2026-11-11)

Following [0094 T5](0094-forever-port-professions-and-character-history.md), [0096](0096-forever-recipe-catalog.md) and [0097](0097-recipe-sightings-and-advice.md), deterministic Server code builds recipe stretches to the next Forever cap (75/150/225/300), a supported Retail expansion cap or an explicit target, using known recipes or catalog-confirmed/observed trainer recipes available at that skill, orange before yellow and green only as a marked slow fallback; orange odds are 1, yellow/green odds are clamped `(grey - skill) / (grey - yellow)`, grey odds are 0, and ranking uses expected crafts times reagent count, then held reagents, then recipe id.
Each stretch carries skill bounds, expected crafts and reagent totals, with a preceding trainer Step and observed Waypoint when needed; the existing Companion delivery carries these Plans as Profession Ideas, Steps complete at their target skill, targets never exceed the known current profession maximum and reaching that maximum (below 300 in Forever, or a known Retail maximum) returns `needs_rank` with only a rank-training Step that completes when the maximum increases, using an observed trainer Waypoint when available and stating requirements only from client data, MCP adds `get_skill_route(game, character, skillLine, target?)`, and the private character page shows stretches, stops, totals and a short odds explanation.
Only wago.tools client tables and player sightings supply facts: `merchantSeen` now retains the latest 200 combined recipe/Trade Goods NPC-item pairs under the existing bounds, prices are shown only from vendor sightings (unconfirmed BuyPrice stays unknown), vendor/drop recipes must already be known, and missing evidence stops a Plan; auction prices, history, compatibility claims and releases remain outside this change.
