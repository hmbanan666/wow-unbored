# 0060. Instance guides

Status: accepted

Raid and dungeon Plans follow journal order, with entrance travel, one Step per boss (or trivial wing), sourced map points and the achievement instructions before the pull. The Server joins cached public DB2 journal and achievement tables by typed ids, optionally using cached journal encounter creatures from the Game Data API; unsupported criteria stay explicitly unmapped, and map points do not imply a known doorway or portal route. Keep 40 Steps, 240-byte Step titles and 120-byte reasons; allow 1,000-byte Step notes for directions and mechanics in either language, with long expanded details scrolling inside the card and a 64,000-character encoded Plan cap so thirteen full boss notes survive delivery.
