# 0074. Public Path pages

Status: accepted

Every published Path has a public, indexable English page (`/paths/<slug>`) rendered on the server from the Path data and Game DB names: what the Path covers, each goal with a short how-to, sources, and a call to install Unbored to track it in game. Pages carry no player data, have stable slugs, canonical URLs, a sitemap and structured data; text is written per Path and reviewed like code. Signed-in players see their own progress on the same page.
