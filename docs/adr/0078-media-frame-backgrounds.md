# 0078. Filled photos and solid render frames

Status: accepted

Photos, instance tiles and own images fill fixed-aspect frames with cover fitting and an overridable focal point, defaulting to center 40%. Creature renders remain centered and uncropped on a solid #181818 interior throughout their frames, matching the background measured in Blizzard's stored files; gold borders stay, while gradients and vignettes are removed. This owner-requested presentation adjustment to ADR 0077 changes no stored images or media processing.
