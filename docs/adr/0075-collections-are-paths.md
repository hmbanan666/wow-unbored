# 0075. Collections are a kind of Path

Status: accepted

A curated collection, such as mounts to get first, is a Path with `kind: collection` in the same `content.paths` catalog as `kind: path` ([0072](0072-paths.md), [0074](0074-public-path-pages.md)). Public pages are `/paths/<slug>` and `/collections/<slug>`. There are no per-object pages: no item, mount, NPC, quest, spell, pet, toy or achievement page.
