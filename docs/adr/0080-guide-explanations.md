# 0080. Sourced explanations in guides

Status: accepted

Guides may mark a game term with a short, sourced explanation, shown on hover or focus and toggled by touch, as requested by the owner. Definitions remain readable in server HTML and linked without scripts; they belong to the guide's Game and may carry verified item or spell identity without querying Retail data for Forever or creating object pages. Icons use only existing own-image media hashes, with no new image processing, and publication stays in the versioned database workflow.
