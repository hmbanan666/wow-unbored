# 0056. Step groups

Status: accepted

Consecutive tasks with the same optional `group` form a Step group done in any order. Inside a group the card's meta line gets two arrows that flip between its open Steps without skipping or counting anything, Skip drops the shown Step at once, and every open Step of the group completes itself from game truth while proximity and zone count only for the shown one; sequential Plans look as in 0.9 (D204-D209). This amends [0038](0038-one-plan-card.md).
