---
name: guide-write
description: Research search queries, brief and write a new Unbored game guide. Use for new guide commissions or a replacement draft; use guide-maintain to audit or refresh an existing publication.
---

1. Read [the publication flow](../../../docs/content-authoring.md) and [the editorial standard](../../../docs/adr/0081-search-led-editorial-standard.md). Identify the Game, existing public URL if any and reader's starting situation. Read adjacent guides to avoid assigning the same primary query to two pages.
2. Complete **search research** in the [brief](references/brief.md) before drafting: one primary query, 3–8 secondary queries from Google autocomplete, People also ask and the top five results, plus intent. Log the searches actually used and the gaps this page will answer. Missing search evidence stays an explicit blocker, never invented demand.
3. Complete the brief's evidence ledger and shape plan. Fetch factual sources this run and record failed access separately. Stop the factual draft if its central answer depends on missing evidence, an incompatible Game/build, invented observation or an unresolved contradiction. Narrow to a supportable question and state the gap.
4. Open with a concrete in-game fact and answer the primary query in the first two sentences. Keep verified names, quantities, locations and mechanics; give each recommendation a reason and a condition that would change it. Follow the brief's metadata, links and intent-based length rules. Plan tables/steps and FAQ in the brief until their content blocks arrive in the later task planned as ADR 0083; do not invent JSON blocks.
5. Mark only terms that interrupt understanding, using the publication flow's syntax. Keep essential advice in prose and verify definitions in this Game. Guide visuals use only our own screenshots; without one, omit the image. Read media rules before using one; compression or format conversion only, no other edits or Wowhead images.
6. Apply every dimension of the [editorial rubric and bad/better examples](../guide-maintain/references/rubric.md), including the interest and banned-pattern passes. Repair failures, validate the structured document and preview its server-rendered page. Read the opening, headings and link labels alone: they must form a useful decision sequence.
7. Deliver the brief, evidence gaps, reviewed database draft or migration, validation and publication instructions. Completion means a reader can act without visiting sources, every factual claim is traceable and the authorized publication path has a concrete artifact. Publication requires task authorization; a writing request alone does not authorize live changes.
