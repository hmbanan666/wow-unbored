# Проверка перед клиентом (0.9.0)

Короткий чек-лист для живого клиента WoW (Retail, Windows). Галочка — работает как написано. Если нет — `/unbored errors` и скрин.

Главное: за всю проверку UI перезагружается только когда ты сам нажал «Отправить», «Обновить» или «Загрузить» после обновления аддона. Ни одна идея, пресет или предмет сами не перезагружают. Нигде нет поля для текста и нигде не спрашивают про время.

Один тег `vX.Y.Z` содержит установщик, zip аддона и `latest.json`. Уже установленные Companion читают `latest.json` с релиза `companion-updater`. Тег ставит владелец.

В сводке задания `notes` — текст релиза; в нём нет «Wisp», строк про CI, clippy, тесты и версий в начале строки. Новых релизов на GitHub не появилось.

## Подпись обновлений (D151–D152)

0.9.0 подписан **старым** ключом (его понимают установки 0.8), но внутри уже **новый** публичный ключ. Замену секрета после релиза делает бот владельца, не агент.

- [ ] Companion 0.8 сам обновился до 0.9.0 (в течение ~20 с после старта или 4 ч). Значит, подпись старым ключом принята.
- [ ] После того как бот сменил `TAURI_SIGNING_PRIVATE_KEY` на новый и выпустил 0.9.1: Companion 0.9.0 сам обновился до 0.9.1.
- [ ] Установка, которая осталась на 0.8 и пропустила 0.9.0, после смены ключа сама не обновляется; ставится руками из релиза, как написано в README.

## План без перезагрузки

- [ ] Нажать пресет (например «Добыть маунта»). UI **не** перезагружается. Сразу быстрый шаг и «Хочешь настоящий план?».
- [ ] Если быстро ничего нет: «Здесь для этого ничего не нашлось. Попробуем другое?» и «Хочешь настоящий план?».
- [ ] «Хочешь настоящий план?» → «Отправить это планировщику?» с пересказом выбора, «Отправить» и «Назад». Ни поля «Что-то добавить?», ни минут.
- [ ] «Назад» возвращает на шаг раньше, ничего не отправив.
- [ ] «Отправить» → один `/reload` от клика → «Я этим занят. Обычно пара минут. Играй, я дам знать.». Быстрый шаг (если был) остаётся выполнимым.
- [ ] Пока запрос в работе, идеи, пресеты и предметы отвечают «По одному делу за раз, я ещё думаю.». В меню «Отменить мой запрос»; после него Бори снова свободен.
- [ ] Ответить на запрос (MCP `list_requests` → `put_plan`). Тост Companion о новом плане, в окне «Твой план ждёт в игре».
- [ ] После обычного времени (~3 мин) «Должно быть готово. Обновить?» и «Обновить» — только если Companion уже записал ответ. Раньше «Обновить» нет.
- [ ] «Обновить», а ответа ещё нет → «Почти. Дай мне ещё пару минут.», следующее «Обновить» не раньше чем через 2 мин.
- [ ] Ответ пришёл → «План получше готов! Берём?» → «Сменить».
- [ ] План на большую ачивку (например, 18 критериев): в `put_plan` все критерии по порядку, план не урезан до 7 шагов и не подогнан под время.
- [ ] Старый запрос не перебивает новый: запрос A, потом B; `put_plan` для B, потом `fail_request` для A. После «Обновить» в игре план B, без петли «готово → обновить → ничего нет».
- [ ] Шаги отмечаются сами (или ✓). В конце звук и «Всё сделано, отлично! Что дальше?».
- [ ] Выйти с незаконченным планом и войти: «С возвращением! Продолжим «…» или что-то новое?».

- [ ] Взять предмет курсором: у Бори «Брось на меня, чтобы спросить». Бросить — предмет в облачке и вернулся в сумку.
- [ ] После этого сумки работают в бою (taint нет).

## Подсказки в тултипе (D142–D147)

- [ ] Хлам, зелья, обычная броня: строки Бори нет.
- [ ] Не собранное ни одним персонажем (игрушка / маунт / питомец / облик): «Бори: Новое для коллекции».
- [ ] Предмет из текущего плана: «Бори: Нужно для плана: <шаг>». Предмет, начинающий невыполненное задание: «Используй: начинает «…»».
- [ ] Реагент, который лежит и у альта: под строкой Бори (или без неё) серая строка «Ещё: Grubbyman 40, банк отряда 200». Больше трёх мест — «… +2». Своих сумок и банка этого персонажа в строке нет.
- [ ] Не больше **двух** строк Бори в одном тултипе: строка-действие и серая «Ещё: …».
- [ ] Реагент чужой профессии, альт с этой профессией уже держит пачку: «Отправь Grubbyman (уже есть 40): почтой» (или «через банк отряда»). Без пачки — «Отправь <альт> (<профессия> <навык>): почтой».
- [ ] Альт с другого ПК (тот же Аккаунт): после синхронизации Companion и «Обновить» его сумки видны в «Ещё: …».
- [ ] Альт, не заходивший больше 60 дней, в «Ещё: …» не попадает.
- [ ] Без Companion, или «Делиться игровыми данными» выключено, или предмета нигде больше нет: строки «Ещё: …» нет.
- [ ] Меню → «Настройки» → «Строки Бори в подсказках» выключить: нет ни строки-действия, ни «Ещё: …». Включить — вернулись.
- [ ] Эпик и BoE никогда не «продай»; привязанное — никогда не «отправь»; «удали» не бывает.
- [ ] Личный совет: MCP `put_item_advice` → через ~30 с Companion обновил `Advice.lua` → после входа строка совета в тултипе.
- [ ] `Unbored_Plan/Advice.lua` на большом аккаунте меньше 260 КБ.

- [ ] `fail_request` → «У меня что-то пошло не так. Попробуем ещё раз?», «Ещё раз» и «Понятно». «Ещё раз» возвращает к «Отправить это планировщику?» с тем же выбором.
