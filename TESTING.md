# Проверка перед клиентом (0.8.0)

Короткий чек-лист для живого клиента WoW (Retail, Windows). Галочка — работает как написано. Если нет — `/unbored errors` и скрин.

Главное: за всю проверку UI перезагружается только когда ты сам нажал «Отправить», «Обновить» или «Загрузить» после обновления аддона. Ни одна кнопка пресета, вопрос или предмет сами не перезагружают.

## Релиз

Один тег `vX.Y.Z` содержит установщик, zip аддона и `latest.json`. Уже установленные Companion читают `latest.json` с релиза `companion-updater`. Тег ставит владелец.

Все задания зелёные, в артефактах `Unbored.Companion_0.8.0_x64-setup.exe`, `Unbored.Companion_0.8.0_x64_en-US.msi`, `Unbored-v0.8.0.zip`, `latest.json` (версия 0.8.0, ссылки на тег `v0.8.0`) и `notes.md`. В сводке задания `notes` — текст релиза; в нём нет «Wisp», строк про CI, clippy, тесты и версий в начале строки. Если версия уже выпущена, там же предупреждение «already released». Новых релизов на GitHub не появилось.
- [ ] В PR: в сводке задания `PR title / notes-preview` — заметки, как будто PR уже влит; задание красное, если туда попала служебная строка.

## Установка

- [ ] Скачать `Unbored.Companion_0.8.0_x64-setup.exe` из релиза `v0.8.0`. SmartScreen: «Подробнее» → «Выполнить в любом случае».
- [ ] Окно Companion: «Connecting...», потом «Waiting for a one-time OK» с именем ПК.
- [ ] Под «Start with Windows» строка «Bory only learns about your own characters. What he knows». Клик по ссылке открывает в браузере раздел README «What Bory knows about you».
- [ ] В списке шагов: папка WoW найдена, Бори установлен (0.8.0) — ещё до одобрения.
- [ ] Одобрить ПК (MCP `list_devices` → `approve_device`).
- [ ] Не позже чем через 30 с: тост «You're connected!» и «Connected! You're all set».
- [ ] В `Interface/AddOns/Unbored_Plan/` есть `Plan.lua`, `Advice.lua` и `Suggestions.lua`.
- [ ] Бори в окне Companion виден в каждой фазе: «Connecting...» — спокойный, ожидание одобрения — зевает, синхронизация — думает, «Connected!» — радуется. Тонкое золотое кольцо стоит на месте, качается только сам Бори. Цвета тёплые (золото, бордо, тёмно-коричневый фон), бирюзового нигде нет.

## Первый вход

- [ ] Запустить WoW, войти персонажем. Без `/reload` и команд.
- [ ] Бори — рыжий кот в тонком золотом кольце, с тёплым кругом за спиной. Ничего не накрывает игровой интерфейс.
- [ ] Бори здоровается «Привет! Чем займёмся?» и показывает идеи (если Companion их уже принёс) или пресеты.
- [ ] Кнопка у миникарты сидит на ободке, её можно тащить по кругу. ЛКМ — показать/спрятать Бори, ПКМ — меню.
- [ ] Нет красных ошибок Lua, нет «интерфейс заблокирован» (taint).

## Облачко и меню

- [ ] ПКМ по Бори → «Настройки»: «Размер Бори» и «Размер облачка» меняются отдельно, «Закрепить на месте», «Спрятать», «Клавиши», «Ещё».
- [ ] Клик по Бори сворачивает облачко в маленькую плашку; клик по плашке — обратно.

## Бори

- [ ] Пока запрос в работе, Бори покачивается и мерцает, рядом с именем бегут точки. Кольцо качается вместе с ним: картинка внутри не съезжает относительно кольца. (`TODO(verify-in-game)`: `Animation:SetTarget` на строке текста для точек.)
- [ ] Ответ пришёл: покачивание останавливается плавно, в конце круга, без рывка (смотреть на верхний край кольца). (`TODO(verify-in-game)`: `Finish()` у повторяющейся анимации в 12.x.)
- [ ] Долгое ожидание («Что-то долго…») — Бори зевает. Готово или «Отправить» — радуется. Иначе — спокойный.
- [ ] Цвета облачка: золотые акценты, выбранная кнопка бордовая с золотой рамкой, тёплый тёмный фон, кремовый текст. Префикс Бори в чате и в тултипах золотой. Бирюзового нет нигде.
- [ ] На русском клиенте везде «Бори», на английском — «Bory».

## Карточка плана

- [ ] Свёрнутая карточка: сверху короткое название плана, под ним шаг на сейчас, строка «зачем» и главная награда ссылкой. Один переключатель «Подробнее» и кнопки «Готово» / «Пропустить».
- [ ] «Подробнее» раскрывает план на месте, без нового окна: точки прогресса, цель, детали, все шаги списком (текущий выделен), «Награда:» со ссылками, внизу время. «Свернуть» — обратно. Стрелка у переключателя разная в двух положениях и смотрит туда, куда раскрывается (`TODO(verify-in-game)`: куда смотрит `IconChevron`).
- [ ] Раскрыть, выйти и войти (или сменить персонажа): карточка снова раскрыта. Свернуть — после входа свёрнута.
- [ ] Шаг с условием («Если у тебя 5 000 …»): над шагом серая строка «Если …». Пока не хватает — «Пока нет» и «3 200 / 5 000» в подробностях; «Пропустить» на таком шаге не считается пропуском. Набрал — зелёное «Готово», без перезагрузки.
- [ ] Старый план из 0.7 (без названия): заголовок — название пресета или «Твой план», а не текст заметки.
- [ ] Окна «Все шаги» и трекера больше нет.

## Идеи

- [ ] С запущенным Companion: войти, подождать ~1 мин, перезайти (или «Обновить»). Клик по Бори без плана: «Привет! Чем займёмся?» и до четырёх идей. У каждой название, справа картинка награды, под ним серая строка («Скоро закончится», «Нет ни у одного из твоих 2 персонажей», «Рядом с местами, где ты играешь»).
- [ ] Наведение на идею: подсказка с целью и наградами.
- [ ] Под идеями в одну строку «Удиви меня» и «Что-то другое...», ниже «Ещё идеи» — раскрывает пять прежних пресетов, «Свернуть» прячет их.
- [ ] Клик по идее с сервера → сразу «Отправить это планировщику?» с названием, целью и «Награда:», кнопки «Отправить» и «Назад». Времени не спрашивает. После «Отправить» в MCP `list_requests` у запроса `topic: "suggestion"`, `suggestionId` и `suggestion` с теми же id; `budget` нет.
- [ ] Идёт праздник или в этой зоне редкий из списка Бори: среди идей есть строка «Идёт прямо сейчас» или «Прямо в этой зоне». Клик сразу даёт быстрый шаг и «Хочешь настоящий план?». Одна и та же награда или праздник не показываются дважды.
- [ ] «Что-то другое...» — по-прежнему с полем «Минуты».
- [ ] Без Companion (или пока идей нет): шесть пресетов, как раньше.
- [ ] Идея, у которой вышел срок, после перезахода пропадает.

## План без перезагрузки

- [ ] Под пресетами нет выбора времени (раньше 30м / 1ч / 2ч), и после пресета Бори не спрашивает, сколько у тебя времени.
- [ ] «Что-то другое...»: под полем желания пустое поле «Минуты, только если есть лимит». Оставить пустым → в MCP `list_requests` у запроса `budget: null`. Ввести 45 → `budget: 45`. Ввести 300 → «Минуты: целое число от 5 до 240, или оставь пустым.», запрос не ушёл.
- [ ] Свой план на большую ачивку (например, с 18 критериями): у планировщика (`put_plan`) в плане все критерии по порядку, план не урезан до 7 шагов и не подогнан под время. Минуты у шагов — только справка.
- [ ] Нажать пресет (например «Добыть маунта»). UI **не** перезагружается. Сразу виден быстрый шаг и кнопка «Хочешь настоящий план?».
- [ ] Если быстро ничего нет: «Быстро тут ничего нет. Подумать как следует?» и сразу поле «Что-то добавить? Можно пропустить.».
- [ ] «Хочешь настоящий план?» → «Что-то добавить? Можно пропустить.» → «Дальше» (можно пустым) → «Отправить это планировщику?» с кратким пересказом выбора и кнопками «Отправить» и «Назад».
- [ ] «Назад» на каждом шаге возвращает на шаг раньше, ничего не отправив.
- [ ] «Отправить» → один `/reload` от клика → «Я этим занят. Обычно пара минут. Играй, я дам знать.», Бори мягко пульсирует и покачивается. Быстрый шаг (если был) остаётся выполнимым.
- [ ] Пока запрос в работе, пресеты, «Спросить» и предметы отвечают «По одному делу за раз, я ещё думаю.». В меню есть «Отменить мой запрос»; после него Бори снова свободен.
- [ ] Запрос, поставленный в 0.7 «при выходе»: после обновления Бори показывает «Отправить это планировщику?» и «Отправить», ничего не потерялось.
- [ ] Ответить на запрос (MCP `list_requests` → `put_plan`). Тост Companion «New plan ready. Bory picks it up next time you log in.», в окне «Your plan is ready in the game».
- [ ] После обычного для планировщика времени (по умолчанию ~3 мин) Бори пишет «Должно быть готово. Обновить?» и «Обновить» — только если Companion уже записал этот запрос как готовящийся. До этого никакого «Обновить» в облачке нет.
- [ ] «Обновить», а ответа ещё нет → «Почти. Дай мне ещё пару минут.», следующее «Обновить» не раньше чем через 2 мин.
- [ ] Ответ пришёл → «План получше готов! Берём?» → «Сменить».
- [ ] «Что-то другое...» → поле желания и «Минуты» → «Дальше» → то же подтверждение, в пересказе — твоё желание в кавычках.
- [ ] Старый запрос не перебивает новый: отправить запрос A, потом запрос B. Ответить на B (`put_plan` с `requestId` B), потом `fail_request` для A. Companion пишет в `Plan.lua` ответ на B; после «Обновить» в игре план B, без петли «готово → обновить → ничего нет».
- [ ] Шаги отмечаются сами (или ✓). В конце звук и «Всё сделано, отлично! Что дальше?».
- [ ] Выйти с незаконченным планом и войти: «С возвращением! Продолжим «…» или что-то новое?».

## Ошибки и ожидания

- [ ] Выйти из Companion (трей → Quit), отправить запрос → «На ПК не запущен Unbored Companion. Запусти его, и я всё подхвачу.»
- [ ] Выключить интернет на ПК, отправить запрос → «Unbored Companion не может достучаться до планировщика. Он пробует сам.» Включить — дошло.
- [ ] Запрос без ответа дольше 10 мин (видно после следующего входа) → «Что-то долго. Попробуй ещё раз или подожди.» и «Ещё раз».
- [ ] `fail_request` → «У меня что-то пошло не так. Попробуем ещё раз?», «Ещё раз» и «Понятно». «Ещё раз» возвращает к «Отправить это планировщику?» с тем же выбором, без перезагрузки.
- [ ] Запрос без ответа больше часа: сервер сам закрывает его, Бори пишет «Этот запрос потерялся. Попробуем ещё раз?».
- [ ] Нигде нет сырых ошибок, id или просьбы набрать команду.
